# СТЕК ПРИЛОЖЕНИЯ

---
### **Основной язык**
- **Go (Golang) 1.25**

### **Стандартные библиотеки Go**
- `net/http` - HTTP клиент и сервер
- `time` - работа с таймерами и интервалами
- `fmt` - форматированный ввод/вывод
- `os/exec` - выполнение системных команд
- `bufio` - буферизованный ввод/вывод
- `os` - чтение/запись файлов

---

##  **Сетевые технологии**

### **HTTP клиент**
- Нативный `http.Client` из стандартной библиотеки
- Таймауты: 30 секунд на запрос
- User-Agent: `Mozilla/5.0` для совместимости

### **Cookie management**
- Ручная обработка cookies через заголовки
- Валидация cookies тестовыми запросами

---


## 🐳 **Работа с Docker**

### **Docker**
- **Multi-stage builds** для минимального размера образа
- **Base image**: `golang:1.21-alpine` → `alpine:latest`
- **Итоговый размер**: ~15-20MB
- **Архитектура**: linux/amd64

### **Docker Compose**
- Упрощенный запуск в development окружении
 ```docker-compose up```
- Конфигурация TTY для интерактивного ввода


---

##  **Тестирование**

### **Unit Testing**
- Встроенный testing пакет Go
- Мокирование HTTP клиента для изоляции тестов
- Тестирование в папке `tests/`

### **Интеграционное тестирование**
- Docker-based тестирование
- Проверка сборки образа
